Your bank statements, understood.
On your machine, and nowhere else.

Drop in a statement PDF. Finance Copilot parses it, checks every row against the running balance, and categorizes every transaction with rules it learns from you. No account, no cloud, no data leaving your computer.

Try the demo Run it locally

Run it locally

uvx finance-copilot

Needs uv (one installer command). Prefer pipx? pipx run finance-copilot. First run takes a minute.

What you get out of the box

Parsing you can check

Every row is verified against the statement's running balance. The green badge means the parse is internally consistent, and you can see it.

Categorization that learns

Rules, your own history, and an optional AI stage. Corrections become learned rules, so it leans on AI less every month.

Insights without logging

Money Map, recurring commitments, expense groups with friends, and a review queue that takes seconds, not evenings.

How it stays private

The database is a SQLite file in your app-data folder. The server binds to 127.0.0.1, so nothing is reachable from the network unless you deliberately expose it. There are no accounts, no telemetry, and no cloud services in the architecture at all. Open your browser's network tab while it categorizes a hundred transactions; you'll see zero outbound requests.

The demo above is the one exception, and it holds only generated sample data. Uploads are rejected by the demo server itself, so your statements cannot land there even by accident.

Want AI categorization? Point it at Ollama on your machine or bring any OpenAI-compatible key. Both are optional; the app works with AI switched off.
